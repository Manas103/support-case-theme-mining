# Support-Case Theme Mining: One-Page Brief

- This brief covers 40,000 simulated support cases from 1,500 accounts.
- TF-IDF plus NMF recovered 12 themes, matching the generating theme at 63.2% purity against an independent Hungarian-algorithm alignment.
- A supervised theme classifier reached 0.86 macro-F1 on a held-out split of 8,000 cases.
- Accounts that filed a case in one of the top 3 highest-risk themes (data loss corruption, security vulnerability concern, performance degradation) lost 18.1 adoption points more than matched controls over the next quarter, estimated from 1,491 nearest-neighbor matched pairs.
